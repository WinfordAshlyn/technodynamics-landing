# Технодинамика

Лендинг на [Astro](https://astro.build/).

## Требования

- Node.js `22.12.0` или новее
- npm

## Установка зависимостей

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

По умолчанию Astro запускает локальный сервер на `http://localhost:4321/`.

## Сборка приложения

```bash
npm run build
```

Готовая статическая сборка будет создана в директории `dist/`.

## Проверка production-сборки локально

После сборки можно запустить локальный preview-сервер:

```bash
npm run preview
```

Команда поднимет сервер для проверки содержимого директории `dist/`.

## Полезные команды

```bash
npm run dev      # запуск проекта для разработки
npm run build    # сборка production-версии
npm run preview  # локальная проверка production-сборки
```
